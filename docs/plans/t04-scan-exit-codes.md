# T-04. `cmd/scan/main.go`: коды возврата и проброс ошибки прохода

- **Приоритет:** P0
- **Оценка:** 0.5 дня
- **Зависит от:** T-01
- **Блокирует:** T-12
- **Основание:** ADR-0001 §5.6, §5.7

---

## Цель

Сделать `scan` пригодным для использования как одноразовая задача: ненулевой код
возврата при неверных аргументах и при сбое всего прохода, при этом сохранить
**нефатальность** покадровых ошибок.

## Контекст

Текущий `cmd/scan/main.go` (28 строк):

```go
if len(os.Args) < 2 {
    fmt.Printf("Usage: %s <directory>\n", os.Args[0])
    return                       // ← код возврата 0 при неверном вызове
}
s := scanner.NewScanner(os.Args[1], parallelism)
_ = s.Scan()                     // ← ошибка прохода глушится, код возврата 0
```

`./scan.sh` обязан возвращать код контейнера (критерий приёмки задачи), поэтому
`0` на любой ошибке делает скрипт бесполезным для приёмки и диагностики.

Важно: `scanner.Scan()` **внутри** логирует ошибки по отдельным архивам и продолжает
работу — это зафиксированное поведение пайплайна («Частично обработанная библиотека»
в edge cases задачи). Его менять нельзя: пропущенные архивы должны быть видны в логах,
но не должны ронять весь проход.

## Что делать

1. Вызвать `logging.Setup()` первым оператором в `main()`.

2. Аргументы:

   ```go
   if len(os.Args) < 2 {
       slog.Error("usage: scan <library-dir>")
       os.Exit(2)     // код 2 зарезервирован под ошибки аргументов (ADR §5.7)
   }
   ```

   Сообщение должно содержать и сам путь, и подсказку про источник конфигурации,
   чтобы ошибка читалась в логах контейнера.

3. Разобрать `SCAN_PARALLELISM` через `config.Lookup` (необязательная переменная),
   сохранив текущую семантику: нечисловое значение игнорируется, дефолт 5.

4. Пробросить ошибку прохода:

   ```go
   if err := s.Scan(); err != nil {
       slog.Error("scan failed", "err", err, "dir", os.Args[1])
       os.Exit(1)
   }
   slog.Info("scan finished", "dir", os.Args[1])
   ```

5. Финальный лог `scan finished` нужен для приёмки: по нему оператор в `docker compose logs`
   видит штатное завершение, а не просто отсутствие ошибок.

6. **Не трогать** `scanner/scan.go`, кроме пунктов T-13 (перевод `log.Printf` на `slog`).
   В частности, не «улучшать» построчную обработку ошибок.

## Критерии приёмки

- [ ] `go build ./...`, `go vet ./...` проходят.
- [ ] `scan` без аргументов → код возврата 2, сообщение в stderr/stdout.
- [ ] `scan /несуществующий/каталог` → код возврата 1 (`scanner.GetFilesByMask` вернёт ошибку
      от `os.ReadDir`), в логах видно, какой каталог не удалось прочитать.
- [ ] `scan /каталог/с/архивами` → код возврата 0, в конце лог `scan finished`.
- [ ] Каталог, где все архивы битые → код возврата **0**, но в логах видно
      `failed to process archive …` по каждому архиву (нефатальность сохранена).
- [ ] `SCAN_PARALLELISM=abc` → используется 5, предупреждения нет, падения нет.

## Риски и примечания

- Известная гонка в `scanner/scan.go:42` (общая переменная `err` пишется из нескольких
  горутин) — **вне объёма** задачи: она не влияет на код возврата и не на логирование.
  Зафиксировать как отдельную будущую задачу, не расширяя этот PR.
- `processArchive` вызывает `defer os.RemoveAll(tempDir)` до проверки ошибки
  `os.MkdirTemp` — тоже вне объёма; при сбое временного каталога возможен `RemoveAll("")`.
