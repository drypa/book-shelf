# T-14. Герметизация теста `format/fb2.TestReadFb2`

- **Приоритет:** P2
- **Оценка:** 0.5 дня
- **Зависит от:** —
- **Блокирует:** —
- **Основание:** ADR-0001 §4 (E14), §7 (K9)

---

## Цель

Убрать предсуществующее падение `go test ./...`, чтобы «зелёный» прогон тестов был
возможен и в CI, и у разработчика.

## Контекст

Проверено на текущем HEAD:

```
--- FAIL: TestReadFb2 (0.00s)
    fb2_test.go:26: open /home/drypa/Downloads/fb2-113437-119690/114594.fb2: no such file or directory
```

Тест читает FB2 по **абсолютному пути вне репозитория**. Плюс сам файл
`format/fb2/fb2_test.go` модифицирован в рабочем дереве (имя функции изменено с
`_TestReadFb2` на `TestReadFb2`, путь заменён) — это **не** часть задачи
docker-compose, и правка должна быть сделана осознанно.

Почему это не в объёме T-03: критерий задачи — «`go vet ./...` и `go test ./...`
не падают на `cmd/bot`», а не «весь `go test ./...` зелёный». Падение в `format/fb2`
предсуществующее и не связано с деплоем; замалчивать его нельзя, но и чинить в рамках
этой задачи — смешение ответственности.

## Что делать

Выбрать **один** из вариантов и обосновать выбор в описании PR:

1. **Тестовая фикстура в репозитории** (рекомендуется). Взять небольшой FB2-файл
   (1–5 КБ) и положить в `format/fb2/testdata/`. Уже существует прецедент:
   `archive/testdata/files.zip`. Тест становится полностью герметичным и проверяет
   реальное поведение парсера, включая кодировки из `charMap` (`windows-1251` и др.).
   Преимущество: покрытие `CharsetReader` появляется автоматически.
2. **`t.Skip`** с пояснением, что нужен локальный файл. Быстро, но тест перестаёт что-либо
   проверять.
3. **Разделить на два теста:** `TestReadFb2` на фикстуре (всегда выполняется) и
   `_TestReadFb2Local` на локальном пути (никогда не выполняется). Сохраняет
   «ручной» сценарий без мусора в прогоне.

Дополнительно:

- привести файл в порядок относительно рабочего дерева: решить, считается ли текущая
  незакоммиченная модификация намеренной, и не затереть её молча;
- проверить `TestReadAllFb2` — он тоже читает локальный каталог
  (`_`-префикс означает «выключен»); привести к тому же решению.

## Критерии приёмки

- [ ] `go test ./...` — код 0 на машине без `/home/drypa/Downloads/…`.
- [ ] Тест не зависит от файлов вне репозитория.
- [ ] `format/fb2/testdata/` в репозитории, если выбран вариант 1; размер фикстуры
      разумный (< 100 КБ).
- [ ] В описании PR явно указано, что падение было предсуществующим, и какой вариант
      выбран (приложить вывод `go test ./...` до и после).
- [ ] Кодировки из `charMap` покрыты хотя бы одним тестом (если выбран вариант 1).

## Риски и примечания

- Фикстура с реальной книгой может содержать авторские права / личные данные — взять
  синтетический или общественное достояние FB2-файл минимального размера.
- Не смешивать с задачами деплоя в одном коммите: отдельный коммит с пометкой
  «предсуществующее падение теста».
