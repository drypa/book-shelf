# T-23. Документация и приёмка контроля доступа

- **Приоритет:** P1
- **Оценка:** 0.5 дня
- **Зависит от:** T-18…T-22
- **Блокирует:** —
- **Основание:** ADR-0003 § 4.6, § 5; задача `docs/tasks/access-control.md`

---

## Цель

Довести документацию до фактического поведения и пройти критерии приёмки задачи
руками; зафиксировать закрытие H2/H1.

## Что делать

1. **`README.md`:**
   - новый раздел «Контроль доступа»: поток регистрации (кнопка → заявка →
     Принять/Отклонить), статусы, где администратор смотрит заявки;
   - `ADMIN_TELEGRAM_ID` в разделе переменных (обязательная; как узнать ID;
     требование: **администратор хотя бы раз написал боту**, иначе доставка
     заявки невозможна — риск RR1 ADR);
   - усилить шаг про права: каталог `DATA_HOST_DIR` должен быть записываем для
     uid 10001 — **бот теперь писатель БД** (создаёт `users`, заявки, решения);
   - диагностика: `sqlite3 data/db/db.sqlite3 "SELECT * FROM users"`;
     примечание, что таблица `users` создаётся ботом и не относится к
     `db-create`/дублям строк.
2. **`AGENTS.md`:**
   - в «Bot command flow»: guard перед `actions`; callback-протокол
     (`req:new`, `adm:approve|decline:<id>`); авторизация решения по
     `ADMIN_TELEGRAM_ID`; бот принимает callback-обновления (фикс H1, recover
     на апдейт);
   - в переменные окружения: `ADMIN_TELEGRAM_ID` (required);
   - в «Layout notes»: `cmd/bot/access.go` — схема `users` принадлежит боту,
     создаётся `EnsureSchema()` при старте; в `storage`/`db-create` не трогать.
3. **Приёмка (чек-лист задачи):**

   - [ ] без `ADMIN_TELEGRAM_ID` — не стартует, внятное сообщение;
   - [ ] незарегистрированный не получает данных библиотеки;
   - [ ] «Зарегистрироваться» → заявка админу со всеми полями + 2 кнопки;
   - [ ] из pending нет дубля заявки и нет поиска;
   - [ ] «Принять» → /start /author /title /result /get работают как раньше;
   - [ ] «Отклонить» → blacklist: ни доступа, ни заявки;
   - [ ] рестарт бота сохраняет approved/declined;
   - [ ] редактирование сообщения / callback не роняют бота (H1);
   - [ ] `gofmt -l .` пусто; `go build ./... && go vet ./... && go test ./...` зелёные.

## Критерии приёмки

- [ ] README/AGENTS.md не противоречат коду (пройти по списку выше).
- [ ] Все чекбоксы задачи `docs/tasks/access-control.md` закрыты или
      обоснованно отложены (записать в задаче).
