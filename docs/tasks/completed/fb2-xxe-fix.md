# Исправление XXE уязвимости в FB2-парсере

## Приоритет
high

## Проблема
XML-декодер в `format/fb2/fb2.go` не блокирует внешние сущности (XXE). При загрузке malicious FB2-файла злоумышленник может прочитать произвольные файлы сервера (например, `/etc/passwd`) или сделать SSRF-запросы к внутренним сервисам через сущности вида `<!ENTITY xxe SYSTEM "file:///etc/passwd">`.

## Цель
Отключить обработку XML-сущностей в `xml.Decoder` для защиты от XXE-атак при парсинге FB2-файлов.

## Пользователи
- Пользователи, загружающие книги в библиотеку (через `scan`)
- Администраторы, обслуживающие библиотеку FB2-архивов

## Сценарий использования
1. Администратор загружает в библиотеку ZIP-архив с FB2-файлами
2. При сканировании `scan` парсятся метаданные FB2 (через `fb2.ReadFb2`)
3. Если FB2 содержит XML-сущности, старый код может выполнить их
4. После исправления сущности игнорируются/вызывают ошибку

---

## Архитектурное решение

### См. ADR-0002

**Полное описание решения:** [`docs/adr/0002-xxe-protection.md`](../adr/0002-xxe-protection.md)

### Техническая реализация

Изменить код в `format/fb2/fb2.go`:

```go
// До:
decoder := xml.NewDecoder(reader)

// После:
decoder := xml.NewDecoder(reader)
decoder.Entity = map[string]string{} // Явно отключаем XML-сущности для защиты от XXE
```

### Обоснование

1. Go's `encoding/xml` по умолчанию не обрабатывает внешние сущности, но
   явное отключение документирует намерение и обеспечивает соответствие
   best practices (OWASP).

2. Установка `decoder.Entity = map[string]string{}` полностью отключает
   разрешение XML-сущностей. При встрече сущности парсер не сможет её
   разрешить и не будет выполнять внешние запросы.

3. Обычные FB2-файлы без сущностей работают без изменений.
   FB2-с malicious сущностями будут отклонены с ясной ошибкой.

## Критерии приёмки
- [ ] FB2-файл с XML-Entity не вызывает ошибку чтения, но не обрабатывает сущности
- [ ] Добавлен unit-тест с FB2, содержащим Entity (`<!ENTITY xxe SYSTEM "file:///etc/passwd">`)
- [ ] Обновлена документация о возможных рисках

---

## Edge cases
- FB2 с неизвестными/невалидными сущностями — должны игнорироваться или вызвать ошибку парсинга
- FB2 с вложенными сущностями (билд-селфе attacks) — защищены отключением сущностей
- Кодировки, использующие специфичные символы — не затрагиваются изменением
